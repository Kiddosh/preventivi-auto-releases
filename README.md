# Preventivi Auto — versioni

Qui vengono pubblicate le versioni di **Preventivi Auto**, l'app Windows per i preventivi dell'officina.

## Installare

Apri **[Releases](https://github.com/Kiddosh/preventivi-auto-releases/releases/latest)** e scarica
`PreventiviAuto-Setup-<versione>.exe`, poi fai doppio click.

Windows potrebbe mostrare "Windows ha protetto il PC": clicca **Ulteriori informazioni → Esegui comunque**
(l'installer non è firmato digitalmente).

## Aggiornamenti

Dalla versione 2.0 l'app installata controlla da sola questa pagina e si aggiorna.

Questo repository contiene solo gli installer: il codice sorgente è privato e i dati
(clienti, preventivi) restano sempre sul PC dove è installata l'app.
